# 浙商积存金实时监控面板 (GoldTracker)

![Dashboard](https://img.shields.io/badge/Status-Active-success) ![Python](https://img.shields.io/badge/Python-3.x-blue) ![Flask](https://img.shields.io/badge/Flask-2.x-green)

这是一个专为桌面端设计的**浙商银行积存金实时监控系统**。它不仅仅是一个价格显示工具，更是一个集成了实时走势分析、自动收益计算和数据持久化的个人投资辅助面板。

## ✨ 核心功能

### 1. 🖥️ 专业桌面仪表盘
- **宽屏适配**：采用 12 栅格响应式布局，完美适配电脑屏幕。
- **红涨绿跌**：符合国内投资者习惯的配色方案（涨红跌绿）。
- **关键指标**：实时展示当前金价、今日涨跌幅、24小时最高/最低价。

### 2. 📈 实时走势图
- **多维度时间轴**：一键切换 5分钟 / 1小时 / 全天 走势。
- **智能降采样**：前端采用高效算法，即使数据量巨大也能保持丝滑流畅，不卡顿。
- **自动刷新**：图表每 3 秒自动更新，捕捉每一次微小波动。

### 3. 💰 智能收益计算器
- **实时盈亏**：输入持仓成本和重量，系统自动计算当前持仓市值。
- **净收益分析**：自动扣除 0.4% 的预估卖出费，直接显示“到手净赚”。
- **自动记忆**：您的持仓设置会保存在本地浏览器中，下次打开无需重新输入。

### 4. 🛡️ 后端数据持久化
- **24小时不间断**：后台守护线程每 10 秒抓取一次数据，即使关闭网页也不会中断记录。
- **历史回溯**：重启服务或刷新网页，历史走势数据依然存在，完美衔接。
- **自动清理**：系统每日自动清理过期数据，只保留当天记录，保持轻量高效。
- **离线可用**：内置所有静态资源（Chart.js, Tailwind），断网环境下依然能完美运行。

## 🚀 快速开始

### 1. 环境准备
确保您的电脑或服务器上已安装 Python 3.x。

### 2. 安装依赖
在项目根目录下运行：
```bash
pip install -r requirements.txt
```

### 3. 启动服务
运行以下命令启动 Web 服务器：
```bash
python3 app.py
```
*注：Windows 用户可能直接使用 `python app.py`*

启动成功后，您会看到类似输出：
```
 * Running on http://127.0.0.1:5001
```

### 4. 访问页面
打开浏览器访问：[http://127.0.0.1:5001](http://127.0.0.1:5001)

## 🌍 服务器部署建议 (7x24小时运行)

如果您想将此服务部署在云服务器（如阿里云、腾讯云）上并保持后台一直运行，建议使用 `nohup`：

```bash
# 后台启动，并将日志输出到 server.log
nohup python3 app.py > server.log 2>&1 &
```

### 常用管理命令
```bash
# 查看服务是否在运行
ps -ef | grep app.py

# 停止服务 (假设进程 ID 是 12345)
kill -9 12345

# 查看运行日志
tail -f server.log
```

## 🛠️ 技术栈
- **后端**: Python, Flask, Threading (Daemon)
- **前端**: HTML5, Tailwind CSS (Local), Chart.js (Local)
- **数据存储**: JSON 文件 (轻量级持久化)
